# AI-Powered-Carbon-Footprint-Sustainability-Management-Platform-Group-1

## Project Overview

The **AI-Powered Carbon Footprint & Sustainability Management Platform** is a full-stack web application developed to support sustainable practices by enabling users to monitor, manage, and analyze their carbon footprint through a secure and user-friendly platform.

The application provides secure user authentication, carbon footprint management, sustainability monitoring, and an interactive dashboard for tracking user activities. It follows a modern client-server architecture with an Angular frontend and a Spring Boot backend, delivering a responsive and scalable solution.

> **Note:** Detailed technical documentation, setup instructions, and implementation details are available in the respective **frontend** and **backend** directories.

---

## Features

- User Registration and Authentication
- Secure Login using JWT Authentication
- Google OAuth 2.0 Sign-In
- Forgot Password and Password Reset
- Role-Based Authentication and Authorization
- Carbon Footprint Management
- Sustainability Dashboard
- Responsive User Interface
- RESTful API Integration
